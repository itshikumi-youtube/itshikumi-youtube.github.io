利用規約

制定日：2026年11月17日

本規約は、「1分IT解説｜しくみ紙芝居」の運営者が使用する動画投稿ツール「it-shikumi uploader」（TikTok 上の表示名「しくみ紙芝居 Uploader」。以下「本ツール」）の利用条件を定めます。

1. 利用者

本ツールは運営者本人のみが利用する非公開のツールです。一般には提供・配布していません。

2. YouTube の規約への同意

本ツールは YouTube API Services を利用しています。本ツールの利用者は YouTube 利用規約 に従うものとします。また、Google による情報の取り扱いは Google プライバシーポリシー に従います。

2-2. TikTok の規約への同意

本ツールは TikTok for Developers の API を利用しています。本ツールの利用者は TikTok 利用規約 および TikTok のコミュニティガイドラインに従うものとします。

3. 利用目的

本ツールは、運営者が自分で制作した動画を、運営者自身の YouTube チャンネルおよび TikTok アカウントへアップロードする目的にのみ使用します。

4. 禁止事項

  • 他人のアカウントや動画を操作すること
  • YouTube 利用規約、コミュニティ ガイドライン、YouTube API Services 利用規約に反する使い方
  • 著作権など第三者の権利を侵害する動画のアップロード

5. 個人情報

情報の取り扱いはプライバシーポリシーに定めます。

6. 免責

本ツールは現状のまま提供され、YouTube 側の仕様変更などにより動作しない場合があります。

プライバシーポリシー

制定日：2026年11月17日

「1分IT解説｜しくみ紙芝居」（以下「当チャンネル」）の運営者が使用する動画投稿ツール（以下「本ツール」）における情報の取り扱いを定めます。

1. 本ツールの目的

本ツールは、運営者が自分自身の YouTube チャンネル（および TikTok アカウント）へ、自作した動画をアップロードするためだけに使用します。第三者のアカウントの操作や、第三者への提供は行いません。

2. YouTube API Services の利用

本ツールは YouTube API Services を利用しています。本ツールを利用する場合、YouTube 利用規約に同意したものとみなされます。Google による情報の取り扱いについては、Google プライバシーポリシーをご確認ください。

3. 取得する情報

  • Google アカウントの認証情報（OAuth アクセストークン・リフレッシュトークン）
  • アップロードする動画ファイル、タイトル、説明文、タグなどの投稿内容

視聴者の個人情報や、運営者以外のユーザーの情報は取得しません。

4. 利用方法

取得した認証情報は、運営者のチャンネルへ動画をアップロードする目的にのみ使用します。

5. 保存と共有

認証情報は運営者の端末内にのみ保存し、外部のサーバーへの送信や第三者への共有・販売は行いません。投稿内容は YouTube（および TikTok）へ送信され、各サービスの規約に従って公開されます。

6. 削除と許可の取り消し

本ツールへの許可は、Google アカウントのセキュリティ設定（サードパーティ製アプリへのアクセス）からいつでも取り消せます。取り消し後、端末内の認証情報は削除します。

8. 改定

本ポリシーは必要に応じて改定し、本ページで告知します。
